# Vault Map

Where things live and which note wins when two disagree. Agents read this first and navigate by it.

## Folders

| Folder | What goes there | Source of truth? |
|---|---|---|
| `Workstreams/` | 4-6 top-level areas, `type: workstream` | yes, for the hierarchy |
| `Projects/` | one note per project you engage Claude on | yes: state, decisions, next steps |
| `Queue/` | one note per task or ask | yes: what someone waits on |
| `Meetings/` | curated meeting notes (only when there's something to say) | yes: purpose and outcome |
| `People/` | one note per person | yes: who someone is |
| `Systems/` | one note per external system or tool | yes: how it works |
| `Daily/` | `YYYY-MM-DD.md` session log. **No checkboxes.** | yes: what happened that day |
| `Archive/` | retired projects (moved here, never deleted); `Archive/Queue/` for swept tasks | historical |
| `Artifacts/` | standalone HTML prototypes, workbooks | no |
| `_Attachments/` | finished deliverables only | no |
| `_System/` | this map, the queue rules, context pack, heartbeats, briefs, agent memory | mixed |
| `_Templates/` | specifications for new notes | no |
| `Personal/` | private. Nothing reads it. | n/a |

## Never read

`Personal/`. And don't open files in `_Attachments/`, `Artifacts/` or `Archive/` unless a project
note names them.
